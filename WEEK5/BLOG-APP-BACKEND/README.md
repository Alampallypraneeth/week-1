### Backend develepment 

1. Create git repo
   git init 

2. Add .gitignore file

3. Create .env file for environment variables and read data from .env with "dotenv" module  [npm i dotenv]

4. Generate package.json (npm init -y)

5. Create express application (npm install express)

6. Connect to Database

7. Add middlewares[body parser, error handling middlewares]

8. Design schemas and create models 

9. Design REST APIs for all resources
